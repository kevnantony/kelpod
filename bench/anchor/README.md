# Anchor suites (forgetting gate G-2)

General-capability suites scored for `base` and `adapter`; G-2 fails if any suite drops more
than `gates.forgetting_max_drop_points` (accuracy points). Loaded by
`zllf.stages.evaluate.anchor`, subsampled to `eval.anchor_items_per_suite` per suite.

`sources.json` records dataset, config, split, row count, sha256 and fetch date per suite.
Regenerate (build host only):
`ZLLF_ALLOW_ONLINE=1 python3 scripts/fetch_bench.py --only mmlu arc_easy gsm8k ifeval json_schema`.

## Fallbacks

The `fallback/` suites ship in the repo so evaluation works fully offline. A fallback is used
only for a category with no fetched suite (`anchor.CATEGORY`): `knowledge_mc`, `arithmetic`,
`instruction_following`, `json_format`.

## Item format (`zllf.core.schemas.EvalItem` JSON lines)

- **Multiple choice**: `choices` holds the option texts and `reference` the correct text. The
  prompt lists the options as `A. ...`. Scored with `loglikelihood` of each letter; argmax wins.
- **Numeric**: `reference` is a number. The last number in the output must match it.
- **Constraint checks**: `reference_json = {"checks": [{"type": ...}, ...]}`. Every check must
  pass. Types: `max_words`, `min_words`, `max_sentences`, `min_sentences`, `contains`,
  `not_contains`, `lowercase`, `uppercase`, `no_commas`, `starts_with`, `ends_with`,
  `bullets`, `paragraphs`, `quoted`, `title`, `json`, `json_only` and `json_equals`.
- **Otherwise**: the normalised `reference` must appear in the output.
